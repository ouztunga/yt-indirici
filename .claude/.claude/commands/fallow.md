# Fallow Codebase Intelligence

Run codebase analysis using Fallow.

## Prompt
Analyze the codebase health using Fallow. Run `npx fallow` in the terminal to inspect the project. 

Identify:
1. Unused files and exports (dead code)
2. Duplicate code blocks
3. Circular dependencies or architecture boundary issues

Report the findings to the developer and propose cleanup tasks.
